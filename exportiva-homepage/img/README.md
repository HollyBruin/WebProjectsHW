## 📁 Gerekli Görseller

- `exportiva-logo-white.png` - Beyaz logo (Hero bölümü için)

## 🎨 Görsel Gereksinimleri

### Logo
- **Format**: PNG (şeffaflık için)
- **Çözünürlük**: En az 80px yükseklik
- **Arka plan**: Şeffaf
- **Renk**: Exportiva kurumsal renkleri

### Takım Fotoğrafları
- **Format**: JPG veya PNG
- **Boyut**: 200x200px (1:1 oran)
- **Kalite**: Yüksek kalite, profesyonel görünüm
- **Stil**: Kurumsal, profesyonel portreler

## 📱 Responsive Görseller

Tüm görseller responsive tasarım için optimize edilmelidir:
- **Desktop**: Orijinal boyut
- **Tablet**: %75 boyut
- **Mobile**: %50 boyut

## 🔧 Optimizasyon

Görselleri web için optimize edin:
- **Sıkıştırma**: Web için optimize edilmiş
- **Boyut**: Gereksiz büyük dosyalar kaçının
- **Format**: Modern tarayıcı desteği
